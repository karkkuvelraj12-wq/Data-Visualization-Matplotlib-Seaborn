# Project 02 — Data Visualization with Matplotlib & Seaborn

## Objective
Create informative, honest charts from Seaborn's Tips dataset using Pandas, Matplotlib, and Seaborn.

## Questions
1. How are total bills distributed?
2. How do tips vary by day?
3. Is a higher total bill associated with a higher tip?
4. Which numeric variables have the strongest correlation?

## Visualizations
- Histogram of total bills
- Box plot comparing tips by day
- Scatter plot of total bill versus tip, coloured by meal time
- Annotated correlation heatmap of numeric columns

The notebook combines the four charts into a 2 × 2 dashboard and saves `tips_visualization_dashboard.png` at 150 dpi.

## How to run
1. Open `Project_02_Data_Visualization.ipynb` in Google Colab or Jupyter.
2. If needed, install dependencies with `pip install pandas numpy matplotlib seaborn jupyter`.
3. Run all cells from top to bottom. The first dataset load may need an internet connection.
4. Check the generated numerical takeaways and dashboard image before submission.

## Files to submit
- `Project_02_Data_Visualization.ipynb`
- `tips_visualization_dashboard.png` (generated when the notebook runs)
- A short written summary containing the four data-driven takeaways

## Interpretation
Correlation indicates association, not causation. Titles and takeaways should describe what the chart supports without overstating the evidence.
